# Female - Vulvar Lubrication Activation Profile

## Purpose

This node defines a female/anatomy-dependent activation process in which [[Female - Vulva]] serves as the primary external anatomical anchor for regional tissue-state change, [[Vaginal Fluid]] involvement, fluid-property alteration, and increased or exposed surface presence.

The process may make [[Female - Vulva to Female - Clitoral Complex Mirror Profile]] available as a contextual traversal route, but Mirror traversal is not an Activation component and does not define lubrication mechanics.

This profile defines activation only. It does not define anatomy, fluid identity, sensory perception, sensory valence, pleasure, desire, symbolic meaning, authorial language, corpus usage, or consent.

## Scope Basis

The profile uses Regional scope because the process includes direct tissue and fluid participation across [[Female - Vulva]], [[Female - Vestibule]], [[Female - Vaginal Canal]], and [[Female - Vaginal Opening]].

[[Female - Clitoral Complex]] remains Mirror context only and does not increase Activation scope.

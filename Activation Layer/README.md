# Activation Layer

## Purpose

The Activation Layer defines governed physiological, embodied, and processual state changes.

It models how responses begin, coordinate, and alter state without redefining canonical anatomy, fluid identity, mirror correspondence, sensory perception, pleasure, desire, symbolic meaning, authorial language, or corpus usage.

```text
Canonical Embodiment
= what exists

Activation Layer
= what changes and how the response begins

Propagation Layer
= how a response moves across systems

Expressive and Meaning Layers
= how the response is perceived, valued, desired, interpreted, or communicated
```

## Classification Model

```text
activation_type
= one controlled structural class

activation_components
= one or more controlled process families

activation_scope
= Local / Regional / Cross-System
```

`Composite Activation` is used when multiple process families are coordinated.

## Scope Rule

```text
Local
= one active anatomical anchor

Regional
= two or more nearby anatomical nodes directly participate

Cross-System
= distinct systems or separated regions are coordinated
```

Adjacency, boundary context, mirror engagement, and candidate Propagation handoff do not increase scope by themselves.

## Layer Boundaries

Activation may reference Canonical Embodiment, Fluid, Mirror, candidate Propagation, candidate Sensory, Pleasure, Desire, Symbolic Meaning, Authorial, and Corpus records.

Activation must not define those systems.

# Fluid Layer

This folder contains fluid entities and fluid relationships.

Fluids should be modelled as reusable ontology objects rather than repeated properties inside unrelated nodes.

Fluid definitions may connect to canonical embodiment, activation, propagation, and meaning systems depending on scope.

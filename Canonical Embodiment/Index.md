# Canonical Embodiment Framework

## Purpose

This folder contains the canonical embodiment roots for the Somatic Meaning Engine.

Canonical Embodiment defines what exists as embodied structure before activation, interpretation, symbolic meaning, authorial use, or corpus annotation are applied.

## Embodiment Roots

The current canonical embodiment roots are:

| Embodiment Root | Framework |
|---|---|
| Female | [[Female Embodiment Framework]] |
| Male | [[Male Embodiment Framework]] |
| Trans Feminine | [[Trans Feminine Embodiment Framework]] |
| Trans Masculine | [[Trans Masculine Embodiment Framework]] |

## Governance Rule

Embodiment roots are complete traversal roots.

Anatomical nodes should be instantiated within a specific embodiment root using the file naming pattern:

```text
Embodiment - Anatomical Node.md
```

Examples:

```text
Female - Nipple.md
Male - Nipple.md
Trans Feminine - Nipple.md
Trans Masculine - Nipple.md
```

Cross-embodiment similarity should be represented later through explicit relationships rather than through a shared embodiment root.

## Construction Status

The four embodiment frameworks are currently draft taxonomies and should be reviewed before anatomical node creation begins.

## Next Steps

1. Review all four embodiment frameworks.
2. Resolve classification questions around Composite, Atomic, Distributed, Transitional, Process, and Modifier nodes.
3. Draft the Anatomical Node Template.
4. Validate the template against all four embodiment roots.
5. Instantiate canonical anatomical nodes only after the template is stable.

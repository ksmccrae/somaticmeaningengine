# Female - Pelvis

## Purpose

This node defines the pelvis as a canonical anatomical region within Female Embodiment.

It exists to provide a clear parent anchor for external genitalia, internal reproductive structures, pelvic floor, perineal structures, urinary structures, pelvic bones, and related downstream traversal.

This node defines anatomical placement and containment only. It does not define activation, sensory experience, mirror behaviour, fluid behaviour, symbolic meaning, authorial terminology, or corpus usage.

---

## Canonical Definition

Female - Pelvis is a composite anatomical region containing pelvic reproductive, urinary, perineal, musculoskeletal, and boundary structures.

It functions as a regional parent node for pelvic anatomical sites and systems in Female Embodiment.

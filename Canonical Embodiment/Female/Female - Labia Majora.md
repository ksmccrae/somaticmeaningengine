# Female - Labia Majora

## Purpose

This node defines the labia majora as a canonical anatomical site within Female Embodiment.

## Canonical Definition

The labia majora are paired outer folds of tissue forming part of the vulva.

This node represents the paired structure as a plural paired node. Left and right labia majora nodes should only be created when laterality becomes ontologically meaningful, such as asymmetry, injury, surgery, scarring, swelling, side-specific activation, sensory difference, image annotation, or corpus-specific annotation.

# Female - Labia Minora

## Purpose

This node defines the labia minora as a canonical anatomical site within Female Embodiment.

## Canonical Definition

The labia minora are paired inner folds of tissue within the vulva, bordering the vestibule.

This node represents the paired structure as a plural paired node. Left and right labia minora nodes should only be created when laterality becomes ontologically meaningful, such as asymmetry, injury, surgery, scarring, swelling, side-specific activation, sensory difference, image annotation, or corpus-specific annotation.

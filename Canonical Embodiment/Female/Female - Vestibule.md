# Female - Vestibule

## Purpose

This node defines the vestibule as a canonical anatomical site within Female Embodiment.

## Canonical Definition

The vestibule is a transitional anatomical space within the vulva that contains openings into urinary and internal genital structures and organizes nearby glandular structures.

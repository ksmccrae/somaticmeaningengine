# Expressive Layers Index

This index routes the expressive systems used by the Somatic Meaning Engine.

Expressive Layers define how embodied processes may be perceived, felt, interpreted, contextualized, sounded, ritualized, temporalized, or environmentally experienced.

They do not define canonical anatomy, biological mechanism, fluid identity, activation mechanics, mirror correspondence, authorial style, corpus truth, or consent.

## Core Layer Boundary

```text
Activation Layer
= physiological process or state change

Expressive Layers
= perceived, felt, interpreted, contextual, sonic, environmental, ritual, or temporal experience

Authorial Layers
= language, style, voice, cadence, and controlled human variation

Corpus
= situated usage in specific works
```

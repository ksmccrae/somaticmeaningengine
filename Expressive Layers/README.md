# Expressive Layers

This folder contains expressive systems used by the ontology.

Expressive Layers define how embodied processes may be perceived, felt, interpreted, contextualized, sounded, ritualized, temporalized, or environmentally experienced.

They do not define canonical anatomy, biological mechanism, fluid identity, activation mechanics, mirror correspondence, authorial style, or corpus truth.

## Governing Document

- [[Expressive Layer Framework]] — Draft v0.1

## Subfolders

| Subfolder | Purpose |
|---|---|
| [[Somatic]] | Whole-body, posture-level, body-state, or embodied-orientation experience |
| [[Sensory]] | Perceived qualities such as pressure, wetness, warmth, ache, texture, intensity, location, rhythm, taste, odour, sound, or contact |
| [[Emotional]] | Affective and motivational orientation, including desire, refusal, ambivalence, longing, aversion, or relief |
| [[Symbolic]] | Interpretive meaning and symbolic significance downstream from embodied experience |
| [[Sonic]] | Heard, rhythmic, tonal, resonant, musical, or acoustic expression |
| [[Environmental]] | Place-based, atmospheric, spatial, seasonal, pressure, material, or weather-related experience |
| [[Liturgical]] | Ritual structure, offering, repetition, vow, invocation, sacrament, or ceremonial sequencing |
| [[Temporal]] | Felt duration, anticipation, delay, recurrence, interruption, simultaneity, or time loss |

## Core Layer Boundary

```text
Activation Layer
= physiological process or state change

Expressive Layers
= perceived, felt, interpreted, contextual, sonic, environmental, ritual, or temporal experience

Authorial Layers
= language, style, voice, cadence, and controlled human variation

Corpus
= situated usage in specific works
```

# Temporal Index

The Temporal sublayer defines felt duration, anticipation, delay, recurrence, simultaneity, interruption, time loss, or cyclic experience.

Temporal records describe experienced time. They do not define objective chronology unless recorded in corpus or structural systems, activation mechanics, symbolic meaning by default, authorial pacing by default, or consent.

## Scope

Temporal records may define experience involving:

```text
anticipation
delay
recurrence
interruption
simultaneity
time loss
suspension
afterwardness
return
cycle
threshold
compression
expansion
```

## Boundary Pattern

```text
Temporal
= felt or experienced time

Activation
= physiological process or state change

Environmental
= atmospheric or spatial context

Symbolic Meaning
= interpretation or significance

Authorial
= pacing, cadence, and structure

Corpus
= situated use in a specific work
```

Temporal profiles may intersect with Activation, Environmental, Symbolic, and Authorial records but must not redefine them.

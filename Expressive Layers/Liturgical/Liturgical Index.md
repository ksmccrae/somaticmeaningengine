# Liturgical Index

The Liturgical sublayer defines ritual structure, offering, repetition, vow, invocation, sacrament, ceremonial sequencing, or governed devotional form.

Liturgical records describe ritualized expressive structure. They do not define theology as truth, biological process, activation mechanics, consent, authorial style by default, or corpus truth.

## Governing Documents

- [[Expressive Layer Framework]] — Draft v0.1

## Scope

Liturgical records may define structures involving:

```text
ritual sequence
offering
invocation
vow
repetition
sacrament
threshold
witness
consecration
return
seal
```

## Boundary Pattern

```text
Liturgical
= ritual or ceremonial structure

Symbolic Meaning
= interpretation or significance

Authorial
= language, cadence, and style

Corpus
= situated use in a specific work
```

Liturgical structure may be used by Authorial systems or Corpus annotation, but it does not define prose style or story truth by itself.

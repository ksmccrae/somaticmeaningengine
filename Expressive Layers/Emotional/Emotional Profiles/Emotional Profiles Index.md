# Emotional Profiles Index

This index tracks Emotional / Motivational Profiles in the Somatic Meaning Engine.

These profiles define affective or motivational orientation. They do not define activation mechanics, sensation, somatic body-state, valence, symbolic meaning, authorial language, corpus truth, or consent.

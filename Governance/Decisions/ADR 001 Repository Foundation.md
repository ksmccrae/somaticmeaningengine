# ADR 001 Repository Foundation

## Status

Accepted

## Decision

The repository will use a natural language folder structure.

## Reason

The structure must work well in GitHub, Obsidian, exported documentation, and future tooling.

## Consequences

- Major folders receive README files.
- Folder names should remain readable.
- Future structural changes require documented justification.

# Architectural Decision Records

This folder contains architectural decision records for the Somatic Meaning Engine.

ADRs record decisions that affect repository structure, ontology governance, metadata standards, edge language, templates, and future tooling.

## Rule

Any future architecture change after the v2 baseline should be documented here before it is implemented.

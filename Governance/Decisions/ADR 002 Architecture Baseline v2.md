# ADR 002 Architecture Baseline v2

## Status

Accepted

## Decision

The v2 repository architecture is now the baseline.

## Reason

The project has reached the point where stable structure is more valuable than continued redesign.

## Consequences

- Folder structure is considered stable.
- File class metadata is considered stable.
- Edge families are considered stable.
- Future architecture changes require an ADR.
- Content creation should now instantiate the baseline rather than redesign it.

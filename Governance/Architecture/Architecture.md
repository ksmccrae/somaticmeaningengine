# Architecture

## Purpose

This document defines the architecture baseline for the Somatic Meaning Engine.

The ontology is organised as a governed, layered knowledge system. Each layer has a distinct epistemic function and should not be collapsed into another layer for convenience.

## Layer Model

| Layer | Function |
|---|---|
| Canonical Embodiment | Defines what exists |
| Activation and Translation | Defines how systems respond |
| Expressive Systems | Defines how experience is perceived and interpreted |
| Authorial Systems | Defines how experience is communicated |
| Corpus | Instantiates the ontology in works |

## Core Principle

The ontology defines the knowledge. The works demonstrate its expression.

## Architecture Status

This architecture is considered the v2 baseline. Future structural changes require an architectural decision record.

# Architecture

This folder contains architecture-level documents for the Somatic Meaning Engine.

These documents define the layered ontology model, architectural baseline, and high-level system structure.

## Purpose

Architecture documents change rarely. They describe the stable shape of the ontology and provide the reference point for future specifications, templates, and nodes.

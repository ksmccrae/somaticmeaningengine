# Naming Standard

## Purpose

This standard defines repository naming conventions.

## Rule

Names should be readable in GitHub, usable in Obsidian, clear in exported documentation, and stable enough for future parsing.

## Folder Names

Folder names should use natural language.

Avoid numbering, underscores, and unnecessary special characters.

## File Names

File names should clearly identify the knowledge object or document they contain.

## Relationship Terms

Relationship terms should remain compact, uppercase, and reusable.

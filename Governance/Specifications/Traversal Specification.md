# Traversal Specification

## Purpose

This specification defines the intended traversal model for the Somatic Meaning Engine.

Traversal describes how a future query or tool may move across nodes and relationships.

## Current Status

Traversal is planned but not yet implemented.

## Traversal Families

Traversal may eventually follow:

- Canonical relationships
- Activation relationships
- Interpretive relationships
- Governance relationships
- Corpus annotation relationships

## Governance

Governance relationships act as control rails. Future traversal should obey constraints, review requirements, deprecated paths, and protected structures.

## Future Capabilities

- Edge weights
- Directionality
- Confidence values
- Scope constraints
- Route preferences
- Blocked paths
- Validation reports

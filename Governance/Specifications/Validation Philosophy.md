# Validation Philosophy

## Purpose

This document defines the validation philosophy for the Somatic Meaning Engine.

Validation should protect coherence without preventing growth.

## Validation Priorities

- Required metadata exists
- File class is clear
- Node type is clear where applicable
- Layer placement is explicit
- Relationships are intentional
- Duplicated knowledge is minimized
- Deprecated structures are not reused accidentally
- Governance constraints are respected

## Future Tooling

Future validation tools may check:

- Missing required fields
- Broken links
- Orphaned nodes
- Duplicate aliases
- Deprecated references
- Missing relationship sections
- Inconsistent tags
- Folder placement issues

## Rule

Validation should make the next thousand nodes easier to maintain.

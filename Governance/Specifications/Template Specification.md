# Template Specification

## Purpose

This specification defines templates as reusable structures for creating consistent repository files.

Templates reduce drift by ensuring repeated file classes follow the same shape.

## Template Classes

| Template Class | Applies To |
|---|---|
| Canonical | Canonical knowledge nodes |
| Translation | Activation, propagation, mirror, and fluid structures |
| Expressive | Somatic, sensory, emotional, symbolic, sonic, environmental, liturgical, and temporal systems |
| Authorial | Voice, story operating systems, example registers, and human drift systems |
| Annotation | Corpus annotations |

## Rule

A repeated structure should become a template before duplication accumulates.

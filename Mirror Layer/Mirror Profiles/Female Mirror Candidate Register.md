# Female Mirror Candidate Register

## Purpose

This register lists candidate female embodiment mirror routes to support future Mirror, Fluid, Activation, Expressive, Authorial, and Corpus traversal.

It is a planning register, not a definition layer.

Candidate mirrors listed here do not define activation mechanics, sensory experience, symbolic meaning, authorial language, or corpus usage.

---

## Governance Rule

```text
Mirror Candidate
= possible traversal route

Mirror Profile
= governed correspondence record

Activation Profile
= later mechanism that may use one or more mirror routes
```

Candidate mirrors should become standalone Mirror Profiles only when the route is structurally useful for graph traversal or downstream validation.

## Construction Criteria

Create a standalone Mirror Profile when the candidate route:

```text
has valid canonical anchors
supports traversal that cannot be cleanly handled by an existing parent mirror
clarifies a boundary needed by Fluid or Activation layers
helps avoid layer collapse in passage annotation
can be governed without defining activation, sensation, symbolism, or authorial usage
```

Do not create a standalone Mirror Profile when the candidate route:

```text
only repeats an existing composite route
requires missing canonical anchors
depends primarily on symbolic interpretation
requires activation mechanics to make sense
would create broken wikilinks or premature layer coupling
```
